# Rock Paper Scissors

A responsive **Rock Paper Scissors** game built using **HTML, CSS, and JavaScript**. The player competes against a computer that randomly selects Rock, Paper, or Scissors.

## 🎯 Game Logic

The computer randomly selects one of three choices: **Rock, Paper, or Scissors**. The player's choice is compared with the computer's choice to determine the result.

* **Rock** beats Scissors
* **Paper** beats Rock
* **Scissors** beats Paper
* Same choices result in a **Draw**

The scores are updated automatically after each round.
